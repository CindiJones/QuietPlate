# Quiet Plate

Quiet Plate is a calm, mobile-first web app for noticing food thoughts, tracking triggers, recognizing patterns, and trying short reset tools.

## What is included

- First-visit welcome page explaining the purpose, process, privacy, and safety positioning
- Daily food-noise check-in
- Six-question reflection assessment
- Trigger and craving tracker
- Automatic pattern insights
- Eleven reset tools, including guided timers
- Educational library
- Personal support-plan builder
- Weekly reflection and summary
- Support and safety guidance
- Print / Save as PDF summary
- Private local storage in the user's browser

## Open the app

No installation is required. Open `index.html` in a modern web browser.

For a public website, upload this folder to a GitHub repository and enable GitHub Pages:

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.

## Privacy

Entries are stored only in the browser's local storage. There is no account system or remote database in this version. Clearing browser storage or using a different device will remove or hide the entries.

## Important

Quiet Plate provides educational and self-reflection tools only. It does not provide medical advice, diagnosis, or treatment. If thoughts about food feel distressing, compulsive, or connected to disordered eating, speak with a qualified health professional.
